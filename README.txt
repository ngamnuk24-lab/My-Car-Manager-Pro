MY CAR MANAGER - PWA package

ไฟล์ในชุด:
- index.html: เว็บแอปจัดการรถยนต์
- manifest.json: ข้อมูลสำหรับติดตั้งเป็นแอป
- sw.js: Service Worker สำหรับ cache เบื้องต้น

คุณสมบัติที่เพิ่มในชุดนี้:
- Dashboard Donut แสดงสัดส่วนค่าใช้จ่ายเป็นเปอร์เซ็นต์และยอดเงินแยกตามหมวด
- รายการซ่อมบำรุงมาตรฐาน พร้อมคำนวณเลขไมล์รอบถัดไป
- ตั้งระยะเตือนซ่อมบำรุงล่วงหน้าได้ (ค่าเริ่มต้น 1,000 กม.)
- ตัวเลือกชนิดน้ำมันเพิ่มเติม เช่น เบนซิน, แก๊สโซฮอล์, E20/E85, ดีเซล B7/B10/B20, NGV และ LPG

วิธีใช้งาน:
1. แตกไฟล์ ZIP
2. นำไฟล์ทั้งหมดขึ้นเว็บโฮสติ้งที่รองรับ HTTPS
3. เปิด URL ผ่าน Safari บน iPhone แล้วเลือก Share > Add to Home Screen

หมายเหตุ: ข้อมูลถูกเก็บใน Local Storage ของเบราว์เซอร์เครื่องนั้น ควรสำรองข้อมูลเป็นระยะ และอย่าล้างข้อมูลเว็บไซต์หากยังไม่ได้สำรอง
